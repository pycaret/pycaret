# CLAUDE.md — `apps/site/` (the public docs / marketing site)

Path-scoped guidance for the Next.js site at pycaret.org. Inherits
from the repo-root CLAUDE.md and complements the existing
[`AGENTS.md`](AGENTS.md) here.

@AGENTS.md

## Stack

- Next.js 16 with App Router, **static export only** (`output: 'export'`)
- TypeScript strict mode
- Tailwind CSS with `ink-*` / `accent-*` palette
- MDX content via `next-mdx-remote-client`
- Shiki for server-rendered code highlighting (zero JS shipped)
- griffe (Python) for static API extraction

## Don't break the static export

- No server-only features. No `next/headers`, no server actions, no
  ISR, no edge middleware. **`output: 'export'`** must keep working
  because pycaret.org deploys to GitHub Pages.
- Metadata routes (`robots.ts`, `sitemap.ts`, `opengraph-image.tsx`)
  must declare `export const dynamic = 'force-static'`.

## MDX rendering

- We use `format: 'md'` (NOT MDX) in `MdxRenderer.tsx`. This is
  deliberate: docstrings and release notes contain `<` and `{`
  characters in code samples / type signatures, and the MDX/JSX
  parser would choke. Markdown mode parses them as literals.
- Code blocks go through Shiki at server-render time. Don't add a
  client-side syntax highlighter.

## Site structure

```
content/
├── docs/<section>/<slug>.mdx     hand-written docs
├── blog/session-NN.mdx           imported from release notes
├── api-tree.json                 generated by gen_api_tree.py
└── changelog.md                  mirror of repo-root CHANGELOG.md
```

Generated content (`api-tree.json`, `blog/session-*.mdx`,
`changelog.md`) is gitignored — `npm run sync` regenerates it on
every build.

## Local dev

```bash
cd apps/site
npm install        # one-time
npm run sync       # generate api-tree.json + import release notes
npm run dev        # http://localhost:3001
```

## Don't

- Don't introduce a runtime feature that breaks `output: 'export'`.
- Don't hand-write content under `blog/session-*.mdx` — they're
  generated from the release-notes file.
- Don't manually edit `content/api-tree.json` — it's regenerated.
- Don't change the design tokens (`ink-*`, `accent-*`) in isolation
  — they have to stay in sync with `apps/web/`'s Tailwind config.
